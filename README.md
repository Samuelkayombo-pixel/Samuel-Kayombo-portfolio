# Samuel Kayombo — IT Student Portfolio

## 1. Project Description

This project is a personal portfolio website developed as part of the ICT251 Web Technologies Activity 3 assignment at Mulungushi University.

The website introduces me as an Information Technology student and presents my interests, learning plan, projects, and skills.

## 2. Technologies Used

* HTML5 for the structure of the website.
* CSS3 for styling, layout, and responsive design.
* JavaScript for interactive features.

## 3. Website Features

* Navigation menu linking to the main sections.
* Personal introduction and hobbies.
* Learning plan and learning schedule table.
* Interactive study hours calculator.
* Projects and skills section.
* Photo gallery with Previous Photo and Next Photo buttons.
* Video and audio playback controls.
* Dark Mode and Light Mode switch.
* Contact form validation and message preview.
* Responsive layout for different screen sizes.

## 4. Project Structure

* `index.html` — Main website page.
* `css/styles.css` — Website styling.
* `js/script.js` — JavaScript functionality.
* `images/` — Photographs used in the gallery.
* `videos/` — Video and audio media files.

## 5. How to Run the Website

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server or a web browser.
4. Navigate through the website and test the interactive features.

## 6. How to Test the Features

* Use the navigation links to move between sections.
* Switch between dark and light modes.
* Enter study hours and days to calculate weekly study time.
* Use the gallery buttons to browse photographs.
* Play the video and audio using their media controls.
* Complete the contact form to test its validation and preview.

**Note:** The contact form is a demonstration. It validates the entered information and displays a preview but does not send an email.
